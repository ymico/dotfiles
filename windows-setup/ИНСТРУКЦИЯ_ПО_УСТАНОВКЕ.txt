========================================================================
ИНСТРУКЦИЯ ПО УСТАНОВКЕ WINDOWS 11 И АВТОНАСТРОЙКЕ (DUAL-BOOT С FEDORA)
========================================================================

--- ЭТАП 1: УСТАНОВКА WINDOWS ---
1. Перезагрузите ПК и загрузитесь с этой флешки Ventoy в режиме UEFI.
2. В меню Ventoy выберите образ Windows 11 (например, Windows11_Client_x64...).
3. Дойдите до экрана выбора диска для установки:
   - ВНИМАНИЕ: Выберите строчку «Незанятое пространство на диске» (Unallocated Space ~330 ГБ).
   - НЕ нажимайте «Создать» и НЕ форматируйте вручную.
   - Просто выберите эту неразмеченную область и нажмите «Далее».
   - Установщик Windows сам создаст нужные разделы и пропишет Windows Boot Manager в уже существующий EFI-раздел nvme0n1p1, не трогая файлы Fedora.

--- ЭТАП 2: АВТОНАСТРОЙКА ПОСЛЕ ВХОДА В WINDOWS ---
1. Вставьте флешку Ventoy.
2. Откройте папку "Windows-Setup" (или запустите "НАСТРОЙКА_WINDOWS.bat" в корне флешки).
3. Кликните правой кнопкой мыши по файлу:
     setup.bat -> «Запуск от имени администратора» (Run as administrator)

Что сделает setup.bat:
- Синхронизирует аппаратные часы BIOS (UTC), чтобы время не сбивалось при переключении между Fedora и Windows.
- Отключит Fast Startup и гибернацию (чтобы разделы не блокировались и Linux их читал).
- Отключит акселерацию мыши (1:1 честный сенсор без сглаживания для CS2 и Rust).
- Установит и включит курсор Bibata Modern Classic (как в Hyprland).
- Включит профиль питания «Высокая производительность» и игровой режим.
- Отключит фоновую запись GameDVR (убирает инпут-лаг и фризы в шутерах).
- Отключит залипание клавиш (Shift x5).
- Вернет классическое контекстное меню проводника Windows 10 (без «Показать дополнительные параметры»).
- Включит отображение расширений файлов и скрытых папок.
- Включит темную тему и аметистовый акцент.
- Удалит предустановленный мусор Windows (Cortana, Bing Search, рекламу).
- Установит библиотеки Visual C++ (2015-2022) x64 и x86.
- Установит приложение NVIDIA App для автоматической установки драйверов RTX 5060.
- Установит браузер Zen Browser, лаунчеры Steam, Epic Games, FACEIT Client.
- Установит Rustcord (нативный Discord-клиент) и создаст ярлыки CS2 и Rust на рабочем столе.

--- ЭТАП 3: АКТИВАЦИЯ WINDOWS ---
Если хотите активировать Windows навсегда:
- Запустите файл "ACTIVATE_WINDOWS.bat" (или в окне PowerShell введите: irm https://get.activated.win | iex)
- В появившемся окне нажмите клавишу [1] (HWID Activation). Windows будет навсегда активирована официальной цифровой лицензией.

--- ЭТАП 4: ЧАСТОТА МОНИТОРА (180 Гц) ---
1. Кликните правой кнопкой мыши по рабочему столу -> «Параметры экрана» (Display settings).
2. Прокрутите вниз -> «Расширенные параметры дисплея» (Advanced display).
3. В строке «Выберите частоту обновления» выставьте 180 Гц (по умолчанию Windows ставит 60 Гц).

--- ЭТАП 5: ВОЗВРАТ МЕНЮ GRUB ПРИ ВКЛЮЧЕНИИ ПК ---
После установки Windows материнская плата может по умолчанию грузить сразу Windows Boot Manager.
Чтобы вернуть меню выбора (Fedora / Windows):
1. Перезагрузите ПК и нажимайте клавишу Boot Menu (F11, F12 или F8).
2. Выберите пункт "Fedora" — система загрузится.
3. В терминале Fedora выполните команду:
     sudo grub2-mkconfig -o /boot/grub2/grub.cfg
4. GRUB автоматически найдет Windows Boot Manager и добавит его отдельным пунктом.
5. В BIOS (F2 / Del) выставьте Fedora на первое место в списке загрузки и включите Secure Boot (для работы FACEIT).
Теперь при каждом включении ПК всегда будет появляться красивое меню GRUB с выбором Fedora или Windows!
